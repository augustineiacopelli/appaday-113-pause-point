Pause Point

A sixty second pause, with a reason prompt, before you can visit the sites you are trying to avoid. The companion browser extension to Temptation Ledger, App 112.

What it does

Add any domain to your blocklist from the toolbar popup. From then on, visiting that domain redirects to a pause screen that asks what is pulling you there, counts down sixty seconds while your reason stays on screen, and only then lets you close the tab or continue. Every outcome, held or yielded, is logged and rolled into a running streak shown right in the popup.

Install it

Download the extension (.zip)
  1. Download the extension ZIP above and unzip it locally.
  2. Open chrome://extensions in Chrome or another Chromium browser.
  3. Turn on Developer mode in the top right corner.
  4. Click Load unpacked and select the unzipped folder.
  5. Pin the Pause Point icon to the toolbar and add your first domain.
This is a sideloaded, developer-mode extension rather than a Chrome Web Store listing. All blocklist data, streak history, and outcomes stay in local browser storage on your machine and are never sent anywhere.

How the pause works

Blocked domains are enforced with Manifest V3's declarativeNetRequest rules, so the redirect happens before the page ever loads, with no network permissions beyond what is needed to rewrite that one navigation. Choosing to continue grants a fifteen minute pass for that domain, tracked with a chrome.alarms timer that reverts it automatically. Choosing to close extends your held streak by one.
